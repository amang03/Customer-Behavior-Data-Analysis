## How to Run This Project

Follow the steps below to set up and explore the project.

### 1. Clone the Repository

Clone the repository to your local machine:
git clone https://github.com/amang03/Customer-Behavior-Data-Analysis.git
cd Customer-Behavior-Data-Analysis
### 2. Run the Jupyter Notebook

Open the `.ipynb` notebook to perform the initial data processing and preparation.

The notebook covers:
- **Data Import:** Loading the raw customer behavior dataset.
- **Exploratory Data Analysis:** Understanding data distributions, trends, and patterns.
- **Data Cleaning:** Handling missing values, inconsistencies, and preparing data for analysis.
- **SQL Database Integration:** Connecting Python to a relational database and loading the processed data.

### 3. Set Up the SQL Database

- Create a new database in MySQL, PostgreSQL, or Microsoft SQL Server.
- Configure the database connection in the Python notebook.
- Execute the Python scripts to load the processed dataset into the SQL database.

### 4. Perform SQL Analysis

Open `customer_behavior_sql_queries.sql` and execute the queries against the created database.

Use SQL to answer key business questions and derive insights into customer behavior, purchasing patterns, and business performance.

### 5. Build the Power BI Dashboard

- Connect Power BI Desktop to the SQL database.
- Import the relevant tables and analytical outputs.
- Open `customer_behavior_dashboard.pbix`.
- Explore the interactive dashboard to visualize key business metrics, customer trends, and analytical insights.

### 6. Explore the Final Dashboard

Interact with the Power BI dashboard using filters, slicers, and visualizations to gain actionable insights into customer behavior and business performance.
